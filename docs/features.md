# 功能说明

本页介绍控制台各功能的用途与使用方法，名称与菜单一致。是否可用取决于站点配置与节点能力。

> 创建各类隧道时，通常都需要：**选择节点 → 选择节点套餐 → 选择客户端 → 填写目标**。节点套餐决定速率、流量包等限制，创建可能消耗积分，详见 [账号与个人中心](account.md)。

## 客户端

「客户端」页面管理运行在内网机器上的客户端：

- **创建 / 编辑 / 删除**：创建后获得一个客户端。
- **连接密钥**：点击「连接密钥」获取该客户端连接服务端所需的密钥。
- **在线状态**：列表实时显示客户端是否在线。
- **日志**：点击「日志」在线查看客户端最近的运行日志，便于排障（需客户端为新版本，详见下文「客户端日志」）。

客户端的安装与连接见 [客户端安装](client-install.md)。

## 端口转发

将内网的 **TCP 端口**映射到节点的公网端口，适合远程桌面、SSH、数据库等。

创建步骤：

1. 选择**节点**（可按 全部 / 我的节点 / 系统节点 筛选），节点会展示可用规则与介绍。
2. 选择该节点下的**节点套餐**（展示套餐说明、速率与流量包）。
3. 选择**客户端**。
4. 填写：
   - **名称**：便于识别。
   - **内网 IP**：目标服务所在地址，本机服务填 `127.0.0.1`。
   - **内网端口**：目标服务端口，如远程桌面 `3389`、SSH `22`。
   - **远程端口**：留空则自动分配；页面会提示该节点可选的远程端口范围。
   - **PROXY Protocol**：不启用 / V1 / V2，需要向后端传递真实客户端 IP 时启用（后端须支持）。
   - **加密 / 压缩**：按需开启，开启会略增延迟。
5. 保存后配置实时下发，列表显示节点分配的公网访问地址。

> 速率限制由所选节点套餐决定。端口转发面向 TCP 服务。

## 域名解析

通过**自定义域名**访问内网的 HTTP/HTTPS 服务（需站点部署网关服务）。

创建步骤：

1. 选择支持域名解析的**节点**（页面展示该节点绑定的域名 / 泛域名）。
2. 选择**节点套餐**与**客户端**。
3. 填写名称、**内网协议**（HTTP/HTTPS）、内网 IP、内网端口，按需开启加密/压缩。
4. 保存后，将你的域名解析（CNAME/A 记录）指向节点，即可通过域名访问内网服务。

## 私有隧道

**不分配公网端口**，凭**访问密钥**由访客端接入，比端口转发更私密。适合只想让特定人访问、不希望端口暴露在公网的场景。

创建步骤：

1. 选择支持私有隧道的**节点** → **节点套餐** → **客户端**。
2. 填写名称与内网目标（内网 IP、内网端口）。
3. 保存后获得**访问密钥**。

访客端访问（在发起访问的机器上运行客户端）：

```shell
./gostc -addr gostc.shop -v -vts 访问密钥:本地端口
```

启动后，访问本机「本地端口」即相当于访问隧道指向的内网服务。多条用英文逗号分隔。

列表操作：流量统计、查看访问密钥、转移隧道、续费（按套餐计费时）、编辑、删除、启用/停用。

> 私有隧道同样需要选择节点；与端口转发的区别在于不暴露公网端口、凭密钥接入。删除隧道不会退还已消耗的积分。

## P2P 隧道

让两端尝试 **NAT 打洞直连**，降低延迟、减少节点流量；打洞失败时回退到节点中继转发。

- 创建方式与私有隧道类似，保存后获得访问密钥。
- 访客端使用 `-p2p` 模式：

```shell
./gostc -addr gostc.shop -p2p -vts 访问密钥:本地端口
```

- 是否允许回退中继转发由节点能力决定；列表会显示中继转发是否生效。

> P2P 成功率取决于两端 NAT 类型，无法保证一定直连；失败时自动走中继。

## 代理隧道

通过节点提供 **SOCKS5 代理**（支持用户名/密码认证），适合把节点作为代理出口。

创建步骤：

1. 选择支持代理的**节点** → **节点套餐** → **客户端**。
2. 设置认证用户名/密码（可选）、远程端口（留空自动分配）。
3. 保存后，在支持 SOCKS5 的客户端中配置节点地址与端口（及认证信息）即可使用。

## 配置隧道

直接下发 **FRP 原生配置**，适合熟悉 FRP 的高级用户。

- 类型：**FRPC**（客户端配置）/ **FRPS**（服务端配置）。
- 配置内容：兼容 **INI / TOML** 格式。
- 选择客户端后保存，配置下发到对应客户端执行。
- 页面会展示平台与地址信息供参考。

> 配置隧道更灵活，但需自行保证配置正确；普通用户建议优先使用端口转发 / 域名解析等可视化功能。

## 我的节点

把自己的**公网服务器**接入为穿透节点，供自己或他人使用。

1. 进入「我的节点」，点击「新增节点」，按提示填写信息。
2. 在公网服务器上以**节点模式**运行客户端：

```shell
./gostc -addr gostc.shop -s -key 节点密钥
```

3. 节点上线后，即可在创建隧道时选择该节点。

> 节点密钥在「我的节点」中查看。节点模式使用 `-s`，与客户端模式（`-key` 客户端密钥）不同。

## 节点套餐

「节点套餐」页面按节点列出可用套餐及其说明、速率、流量包等。

- 创建隧道/转发时**必须选择**一个节点套餐。
- 套餐决定速率限制等能力，并可能涉及积分计费（是否计费、金额以套餐说明为准）。
- 按套餐计费的隧道到期后可**续费**。

**流量包**：套餐可设置一个流量上限（单位 GB），`0` 表示不限制。

- 用量统计该隧道在计费窗口内的**上行 + 下行**总流量。
- 循环计费套餐（如月卡）的流量包**随续费周期重置**；一次性 / 免费套餐为累计总量，不重置。
- 流量包用完后，**新的连接会被拒绝**（提示流量不足），已建立的连接不会被主动掐断；列表会显示「流量包已用完」。续费或管理员调整后可恢复。

> 若某节点显示「暂无套餐」，则该节点当前不可用于创建隧道，请联系管理员或更换节点。

## 客户端日志

在「客户端」列表点击「日志」，可**在线查看客户端最近的运行日志**，无需登录内网机器，便于快速排障。

- 支持按日志类型（FRP / Client / Node）与关键词过滤，可自动刷新。
- 日志来自客户端本地缓存的最近记录。
- **需要客户端为新版本**；旧版本客户端无此能力，会提示不在线或版本过低。
