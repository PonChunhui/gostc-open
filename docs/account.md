# 账号与个人中心

本页介绍账号相关操作：获取账号、登录、个人中心（积分 / 签到 / 绑定邮箱 / 修改密码 / 两步验证），以及忘记密码时如何重置。

## 获取账号

- **站点未开放自助注册时**：账号由管理员分配，请联系站点管理员开通。
- **站点开放注册时**：登录页会出现「注册」标签，填写账号、密码与图形验证码即可自行创建账号。

> 是否开放注册由站点管理员控制。看不到注册按钮，说明当前未开放注册，请联系管理员。

## 登录

1. 打开平台首页，点击「登录」。
2. 输入账号与密码。
3. 若站点开启了图形验证码，按提示输入验证码。
4. 若你的账号开启了 **TOTP 两步验证**，还需输入验证器 App 生成的 6 位动态码。

## 个人中心（仪表盘）

登录后进入「仪表盘」，即个人中心，可查看与管理：

| 项目 | 说明 |
| --- | --- |
| 积分 | 账号当前的积分余额，创建隧道时可能按节点套餐消耗积分 |
| 用户组 | 当前所属用户组及其权益（节点 / 套餐白名单、隧道数量、月流量）；限时组会显示到期时间 |
| 签到 | 站点开启签到时，每日签到可随机获得积分（以站点实际配置为准） |
| 卡密兑换 | 输入在发卡平台购买的卡密，兑换积分或 Pro 用户组权益 |
| 邮箱 | 绑定邮箱后，忘记密码可通过邮箱重置 |
| 修改密码 | 修改登录密码 |
| 两步验证（TOTP） | 开启 / 关闭 TOTP 两步验证，提升账号安全 |

### 绑定邮箱

1. 在个人中心点击「绑定邮箱」。
2. 输入邮箱地址，点击「发送」获取邮箱验证码。
3. 填入验证码并确认，完成绑定。

> 绑定邮箱后，忘记密码时可通过邮箱重置密码，建议提前绑定。

### 开启两步验证（TOTP）

1. 在个人中心点击「开启两步验证」。
2. 使用验证器 App（如 Google Authenticator、Microsoft Authenticator、1Password 等）扫描页面展示的二维码。
3. 输入 App 生成的 6 位动态码确认开启。
4. 开启后，每次登录都需额外输入 TOTP 动态码。

> 请妥善保管验证器。若更换手机或丢失验证器导致无法生成动态码，请联系管理员协助处理。

## 积分

积分是平台的使用额度：

- **消耗**：创建隧道 / 端口转发等时，可能按所选**节点套餐**消耗积分（是否消耗、消耗多少由套餐决定）。
- **获取**：站点开启签到时可通过每日签到获得；管理员也可为用户发放积分。
- **注意**：删除隧道**不会退还**已消耗的积分。

> 具体计费规则以各节点套餐的说明为准，或咨询站点管理员。

## 卡密兑换（Pro 功能）

卡密（CDK）是一串由管理员批量生成的兑换码，通常通过**发卡平台**购买获得。兑换后可立即获得积分和 / 或 Pro 用户组权益。

### 如何兑换

1. 在发卡平台购买卡密，获得一串卡密码。
2. 登录后进入「个人中心（仪表盘）」，点击「兑换卡密」。
3. 输入卡密并确认，兑换成功后积分与用户组权益**立即生效**。

### 卡密能兑换什么

每张卡密属于一个批次，批次决定了兑换内容，可组合：

- **积分**：直接增加账号积分余额。
- **Pro 用户组**：将账号升级到指定用户组，享受该组的节点 / 套餐白名单、隧道数量与月流量等权益。
  - **限时组**：按批次设定的天数计时，到期后**自动恢复**兑换前的原用户组。
  - **永久组**：天数为 0 时永久生效。
  - 重复兑换同一限时组会**累加时长**；已是永久组时再兑换同组不改变状态。

### 注意事项

- 每张卡密**只能兑换一次**，兑换后即失效；已停用或已兑换的卡密无法再次使用。
- 卡密不区分大小写，输入时会自动转为大写并去除首尾空格。
- 管理员可在后台「卡密管理」生成批次、导出未使用卡密（用于上传发卡平台）、停用 / 启用卡密。

## 忘记密码

重置密码需要**账号已绑定邮箱**，且站点管理员已配置邮件服务。

1. 在登录页点击「忘记密码」。
2. 输入账号与图形验证码，点击「发送邮箱验证码」。
3. 填入邮箱收到的验证码并提交。
4. 重置成功后，**新密码会发送到你的邮箱**，请使用新密码登录。

> 若未绑定邮箱，或站点未配置邮件服务，则无法自助重置，请联系管理员在后台重置密码。
