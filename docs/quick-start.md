# 快速上手

完成一次内网穿透只需要五步：**获取账号 → 创建客户端 → 下载并连接客户端 → 添加隧道 → 访问服务**。

## 1. 获取账号并登录

- 站点开放注册时：在登录页「注册」标签自行创建账号。
- 站点未开放注册时（看不到注册按钮）：请联系站点管理员分配账号。

拿到账号后登录进入控制台。详见 [账号与个人中心](account.md)。

## 2. 创建客户端

1. 进入「客户端」页面，点击「创建」，填写名称等信息。
2. 创建成功后，在列表中点击「连接密钥」获取该客户端的密钥。

> 连接密钥是客户端连接服务端的凭证，请妥善保管，不要泄露给他人。

## 3. 下载并连接客户端

在首页或「客户端下载」页面下载对应平台的客户端：

- **Windows 图形版（gostc-gui.exe）**：双击运行（需要管理员权限），在界面中添加客户端，填入服务端地址与连接密钥，启动即可。
- **命令行版**：

```shell
# Windows
gostc-cli.exe -addr gostc.shop -key 连接密钥

# Linux
./gostc -addr gostc.shop -key 连接密钥
```

平台 `gostc.shop` 默认启用 TLS，无需额外参数；自建服务端未启用 SSL 时追加 `--tls=false`。详见 [客户端安装](client-install.md)。

客户端启动后，回到网页「客户端」列表，状态变为**在线**即连接成功。

## 4. 添加隧道

以「端口转发」为例：

1. 进入「端口转发」页面，点击「创建」。
2. 选择**节点**（可按 全部 / 我的节点 / 系统节点 筛选），再选择该节点下的**节点套餐**。
3. 选择刚才创建的**客户端**。
4. 填写名称、内网 IP（如 `127.0.0.1`）、内网端口（如 `3389`）；远程端口留空则自动分配（页面会提示可选远程端口范围）。
5. 按需设置 PROXY Protocol、加密、压缩，保存。

保存后配置实时下发到客户端，列表会显示节点分配的公网访问地址。

> - 速率限制由所选**节点套餐**决定，无需逐条设置。
> - 创建隧道可能按套餐消耗积分，详见 [账号与个人中心](account.md)。

其他类型（域名解析、私有隧道、P2P 隧道、代理隧道、配置隧道）见 [功能说明](features.md)。

## 5. 访问服务

使用列表中给出的公网地址访问内网服务，例如：

- 远程桌面：`mstsc /v:节点地址:公网端口`
- SSH：`ssh -p 公网端口 user@节点地址`
- HTTP：浏览器直接访问 `http://节点地址:公网端口`

## 排障

- 客户端不在线：检查客户端进程是否运行、服务端地址与密钥是否正确、网络是否可达。
- 查看客户端运行日志：在「客户端」列表点击「日志」，可在线查看最近日志（需客户端为新版本）。
- 更多问题见 [常见问题](faq.md)。
