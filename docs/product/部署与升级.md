# 部署与升级指南（平台增强 P1–P6）

> 配套：[产品文档](产品文档.md)、[PRD](PRD.md)、[开发路线图](开发路线图.md)。本文说明增强功能引入的**新配置项**、**启用方式**与**升级注意事项**。所有新能力默认关闭或兼容旧部署，按需开启。

## 1. 升级总览

- 数据库：gorm AutoMigrate **只增列/增表，不删改**，升级即自动迁移。新增表：`system_audit_logs`、`gost_tunnel_health`、`system_alert_rules`、`system_alert_logs`、`gost_metrics`、`system_certs`、`gost_node_groups`、`system_orders`、`system_bills`、`system_api_tokens`、`system_tunnel_templates`、`system_client_versions`。
- 隧道表新增列：host/forward 高级字段（locations/健康检查/负载均衡/备节点等）、p2p（nat_type/relay_bytes/keep_tunnel_open）、5 类隧道 backup_node_code/failover_enable、节点 group_code/priority/weight、准入 black_enable/black_list。
- 密码：新写入用 bcrypt；存量 MD5 登录成功后**透明升级**，无需手工迁移。
- 凭据加密：`encrypt.key` 为空时保持明文（兼容旧部署）；配置后新写入加密，读取自动解密。

## 2. 新配置项（server 配置 yaml）

```yaml
# 缓存后端（M3）：local 默认；redis 用于多实例共享
cache:
  type: local            # local | redis
  redis:
    addr: 127.0.0.1:6379
    pwd: ""
    db: 0
    prefix: gostc

# 敏感凭据加密（M2）：空=关闭（兼容旧明文）
encrypt:
  key: ""                # 建议 32+ 字节随机串；配置后 CustomKey/证书凭据/API Token 哈希等加密存储

# 隧道健康探测 + 故障转移（M1/M8）
health:
  enable: false          # 开启主动探测与故障转移扫描
  interval-sec: 30       # 探测周期
  concurrency: 16        # 并发探测数
  probe-timeout-sec: 5   # 单次探测超时

# 实时指标与历史聚合（M7）
metric:
  enable: false
  aggregate-sec: 60      # 历史聚合周期
  retention-days: 7      # 历史保留天数

# 证书 ACME 自动签发（M4）
acme:
  email: admin@example.com
  ca: ""                 # 空=Let's Encrypt 生产；调试可填 staging URL
  provider: dnspod       # 默认 DNS provider：dnspod | cloudflare | alidns
  cert-dir: ""           # 空=<base>/data/certs
  proxy-url: ""          # 网关 proxy 基址（如 http://127.0.0.1:8080），签发后推送证书；空=不推送

# 数据库读写分离（M8，仅 mysql 生效）
db-resolver:
  enable: false
  replicas:              # 从库完整 DSN 列表，写主库读随机从库
    - user:pass@tcp(replica-host:3306)/gostc?charset=utf8mb4&parseTime=True

# 支付（M9）：本期仅沙箱可用，真实渠道资质预留
pay:
  sandbox-key: ""        # 沙箱回调签名密钥，空=默认值
  alipay: { app-id: "", private-key: "", public-key: "" }
  wechat: { mch-id: "", app-id: "", api-key: "" }
  stripe: { secret-key: "", webhook-secret: "" }
```

## 3. 功能启用清单

| 功能 | 启用方式 |
|---|---|
| 审计日志（M2） | 默认开启，自动记录 admin/normal 写操作；admin `system/audit/page` 查询 |
| 账号锁定（M2） | 默认开启，连续 5 次失败锁定 15 分钟 |
| IP 黑名单（M2） | 隧道准入设置 blackEnable=1 + blackList |
| Redis 缓存（M3） | `cache.type: redis`；连接失败自动降级本地缓存 |
| 健康监控/告警（M1） | `health.enable: true`；面板「告警」配置规则（email/webhook 渠道） |
| 实时曲线（M7） | `metric.enable: true`；面板「指标」查看 |
| 证书自动化（M4） | 配置 `acme`；面板「证书」创建→签发，支持 DNSPod/Cloudflare/阿里云 DNS-01 |
| 网关增强（M6） | proxy 配置 `ip-routes`/`http3`/`default` 兜底；通配符非标端口已修复 |
| frp 高级能力（M5） | 隧道编辑「高级」折叠区：负载均衡/健康检查/HTTP 路由/tcpmux/范围端口/带宽 |
| 故障转移（M8） | `health.enable: true` + 隧道 failoverEnable=1 + 备节点或节点分组 |
| 节点分组调度（M8） | admin「节点分组」创建组，节点设 groupCode/priority/weight |
| 读写分离（M8） | `db-resolver.enable: true` + replicas（仅 mysql） |
| 支付/订单（M9） | 面板「充值」沙箱下单；真实渠道需配置商户资质 |
| API Token/批量/模板/OpenAPI（M10） | 面板「API Token」「模板」；`/api/v1/public/openapi/docs` 在线文档 |
| 客户端自动更新（M11） | admin「客户端版本」发布；客户端查 `/api/v1/public/client/version/latest` |
| P2P NAT 预检/中继计费（M12） | P2P 列表「NAT 预检」；中继流量自动累计 relay_bytes |

## 4. 网关 proxy 新配置

```yaml
http3: false             # 启用 HTTPS over QUIC（需 UDP 放行）
default:                 # 兜底路由：无匹配 Host 时转发（target 空=关闭）
  target: ""
ip-routes:               # 按 IP 精确路由（无 Host/SNI 场景）
  "114.66.40.58":
    target: http://127.0.0.1:58431
domains:
  "*.x01.gostc.shop":
    target: http://127.0.0.1:58431
    sni: ""              # 回源 TLS ServerName（现已真实生效）
    origin: ""           # 回源 Origin 改写（现已真实生效）
    disable-https: false # 仅 HTTP 服务（现已真实生效）
```

## 5. 升级注意事项

1. **先备份数据库**再升级（虽然 AutoMigrate 只增不删）。
2. `encrypt.key` 一旦设定**不可丢失**，否则已加密凭据无法解密；更换密钥需先解密迁移。
3. 开启 `health.enable` 后探测会访问节点 httpPort/转发口，确保面板服务器到节点网络可达。
4. 证书 DNS-01 需在对应 DNS 服务商创建 API 凭据；签发后通过 `acme.proxy-url` 推送到网关。
5. 读写分离要求从库已同步主库结构；从库延迟需自行监控。
6. 真实支付渠道（支付宝/微信/Stripe）本期仅框架，接入商户资质后方可线上收款。
7. 前端增强页面需重新构建 web（`pnpm run build`）；i18n 默认中文，可切换英文。

## 6. 质量门禁（CI）

`.cirrus.yml` 含：server 编译+单测（pkg/cache/service.common/task/client_version）、proxy 编译+匹配回归、client 编译、web 构建。本地等价命令：

```bash
cd server && go build ./... && go test ./pkg/... ./repository/cache/... ./service/common/... ./task/... ./controller/public/client_version/...
cd proxy  && go build ./... && go test ./pkg/proxy/...
cd client && go build ./...
cd web    && pnpm install && pnpm run build
```
