# 证书自动下发多网关 + 绑定收口 + 转移跟随（CCG 归档）

> 归档载体说明：本会话无 cg MCP 工具，按既定约定以本文档作为可检索归档载体（六要素齐全）。

- **功能名**：证书自动下发多网关 / 绑定域名引用收口 / 故障转移证书跟随（v2.0.13-certpush）
- **生效条件**：
  - 面板 `server` ≥ certpush；网关 `gostc-proxy` ≥ certpush（含 `mergeDomainConfig` + `/domain/delete`）；节点客户端 ≥ certpush（含 `server_domain_remove`）。
  - 证书 `SystemCert.Status=VALID`；推送目标由 `resolveCertNodeCodes` 解析（属主校验；节点后缀匹配仅管理员）。
  - 绑定域名引用需 `host.CertCode` 指向本人 VALID 证书且域名覆盖（通配不覆盖裸域）。
- **子功能**：
  1. 签发/续期/上传 → `pushCert` 多目标 `NodeRenewDomain`（forceHttps=-1 保留原跳转）+ 兼容 `acme.proxy-url`；结果写 `PushSummary`。
  2. `cert Update` 已签发拒改域名；`cert Delete` 被引用拒删 / 否则 `NodeRemoveDomain(purgeCert)`。
  3. 绑定弹窗仅引用证书（删手动 textarea）；存量快照兼容旧客户端。
  4. 解绑 / 删隧道 / 转移源网关 → `NodeRemoveDomain` 清理旧路由。
  5. `failover.doSwitch` 用 `certpick.ForDomain` 取证书推备网关 + 清源网关；换后缀解析通配证书。
  6. `certExpireScan` 增 SystemCert 过期/临期告警。
- **执行**：
  - 代码：`server/service/normal/cert/service.push.go`、`server/service/common/certpick`、`server/service/engine/cmd.node.go`（NodeRenewDomain/NodeRemoveDomain）、`server/router/rpc/frp.go`、`server/task/{failover,cert}.go`、`proxy/bootstrap/api.go`、`client/internal/service/event/server_domain.go`、`web/src/views/normal/gost_client_host/index.vue`、`web/src/views/normal/cert/index.vue`。
  - 部署：6 网关 + 6 节点 + 面板 `v2.0.13-certpush`（docker 重建 / systemd 替换）。
- **验证方式**：
  - 单测：`certpick`、`cert/service.push`（权限/通配/引用）、`proxy/bootstrap`（mergeDomainConfig）、`task`。
  - 生产：续期 `*.yng.linux66.cn` → `pushSummary="推送网关 1 个: b2020dca…"`；118.195 loopback:443 SNI=probe.yng 返回续期后证书（notAfter 2027-02-26 11:25:48 GMT）；`POST /domain/delete` 幂等 success。
- **不适用条件**：
  - 旧网关（< certpush）无 `/domain/delete`、不识别 forceHttps=-1 → 清理/续期保留语义失效。
  - 旧节点客户端（< certpush）不处理 `server_domain_remove` → 源网关路由残留。
  - 通配证书不覆盖裸域；普通用户证书不能推他人/平台网关（权限收口）。
  - 未配置任何目标（无属主隧道且非管理员后缀匹配）时仅落盘不推送。
