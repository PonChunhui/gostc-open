# 常见问题

## 账号

### 为什么看不到注册按钮？

是否开放注册由站点管理员控制。看不到「注册」标签说明当前未开放自助注册，请联系管理员分配账号。详见 [账号与个人中心](account.md)。

### 忘记密码怎么办？

重置密码需要**账号已绑定邮箱**，且站点已配置邮件服务：

1. 登录页点击「忘记密码」，输入账号与图形验证码，发送邮箱验证码。
2. 填入验证码提交，**新密码会发送到你的邮箱**。

若未绑定邮箱或站点未配置邮件服务，无法自助重置，请联系管理员在后台重置。建议平时在个人中心提前绑定邮箱。

### 积分是什么？创建隧道要消耗积分吗？

积分是平台的使用额度。创建隧道/转发时可能按所选**节点套餐**消耗积分，是否消耗、消耗多少以套餐说明为准。站点开启签到时可每日签到获得积分，管理员也可发放积分。**删除隧道不会退还**已消耗的积分。

### 如何修改密码 / 开启两步验证？

登录后进入「仪表盘」（个人中心），可修改密码、绑定邮箱、开启/关闭 TOTP 两步验证。开启 TOTP 后每次登录需额外输入验证器动态码。

## 客户端

### 客户端一直不在线？

按顺序排查：

1. 客户端进程是否在运行（命令行是否报错、图形版状态是否启动）。
2. **服务端地址**是否正确、网络是否可达（能否 ping 通 / 访问服务端）。
3. **连接密钥**是否正确（与网页「客户端 → 连接密钥」一致）。
4. **TLS 设置**是否匹配：平台 `gostc.shop` 默认启用 TLS；自建服务端未启用 SSL 时须加 `--tls=false`。
5. 查看客户端日志定位具体错误（见下条）。

### 点击「日志」提示不在线或版本过低？

客户端日志功能需要**新版本客户端**。请从平台「客户端下载」获取最新安装包并更新客户端；旧版本客户端没有上报日志的能力。客户端确实离线时也会提示不在线。

### 能同时运行多个客户端 / 节点吗？

系统服务名固定为 gostc，无法用系统服务同时运行多个实例。需要多开时，请用 pm2、supervisor 等进程管理工具直接启动多个进程（各自使用不同的密钥）。

### 连接密钥泄露了怎么办？

密钥与客户端一一对应，泄露后他人可冒用该客户端。请删除该客户端并重新创建（获得新密钥），再更新内网机器上的客户端配置。

## 连接与访问

### 端口转发后访问不通？

1. 确认客户端**在线**，且隧道已启用。
2. 确认访问的是列表给出的**节点公网地址 + 远程端口**。
3. 确认内网服务确实在监听所填的**内网 IP + 内网端口**（本机服务用 `127.0.0.1`）。
4. 确认远程端口在节点允许的范围内（创建页会提示可选范围），且节点防火墙放行了该端口。
5. 端口转发面向 **TCP** 服务；请确认目标服务是 TCP。

### 创建隧道时没有可用节点 / 提示暂无套餐？

- 节点需在线且具备对应能力（端口转发 / 域名解析 / 私有隧道 / 代理等）。
- 每个节点需配置**节点套餐**后才能用于创建隧道；若显示「暂无套餐」，请联系管理员配置或更换节点。
- 也可在「我的节点」接入自己的公网服务器作为节点。

### 私有隧道和端口转发有什么区别？

- **端口转发**：分配一个公网端口，任何能访问该端口的人都可访问，适合公开服务。
- **私有隧道**：不分配公网端口，凭**访问密钥**由访客端接入，更私密，适合只给特定人访问。
- 两者都需要选择节点。私有隧道的访客端用 `-v -vts 密钥:本地端口` 访问。

### P2P 隧道没有直连？

P2P 成功率取决于两端的 NAT 类型，无法保证一定打洞成功。失败时会自动回退到节点中继转发（是否允许回退由节点能力决定），功能仍可用，只是延迟/流量走节点。

### 域名解析访问不了？

1. 确认站点已部署**网关服务**，且所选节点支持域名解析。
2. 确认你的域名已正确解析（CNAME/A 记录）指向节点。
3. 确认内网协议（HTTP/HTTPS）、内网 IP 与端口填写正确，内网服务正常。

## 其他

### 图形版提示缺少 WebView2？

Windows 图形版依赖 WebView2 运行时。按提示安装即可，Windows 11 一般已内置。也可改用命令行版。

### 在哪里下载客户端？

平台首页的「客户端下载」页面提供 Windows 图形版、Windows 命令行版、Linux 命令行版安装包，请从平台下载以匹配服务端版本。详见 [客户端安装](client-install.md)。
