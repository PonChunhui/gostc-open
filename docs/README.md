# GOSTC 概述

GOSTC 是一个**基于 FRP 的内网穿透管理平台**，支持多用户、多节点。所有穿透配置都在网页上完成、实时生效，无需登录内网机器修改配置文件。

## 我能用它做什么

- **远程访问内网设备**：把内网的远程桌面、SSH、数据库等映射到公网节点，随时随地访问。
- **发布内网网站**：通过自定义域名访问内网的 HTTP/HTTPS 服务。
- **私有隧道 / P2P**：凭访问密钥访问对方内网服务，或尝试点对点直连降低延迟。
- **代理隧道**：通过节点提供 SOCKS5 代理。
- **自带节点**：把自己的公网服务器接入为穿透节点。

## 功能一览

以下功能与控制台菜单一一对应（是否可用取决于站点配置）：

| 菜单 | 说明 |
| --- | --- |
| 客户端 | 管理内网机器上的客户端：创建、查看在线状态、获取连接密钥、查看日志 |
| 端口转发 | 将内网 TCP 端口映射到节点公网端口 |
| 域名解析 | 通过自定义域名访问内网 HTTP/HTTPS 服务（需网关服务） |
| 私有隧道 | 不暴露公网端口，凭访问密钥由访客端接入 |
| P2P 隧道 | 两端尝试 NAT 打洞直连，失败时回退中继转发 |
| 代理隧道 | 通过节点提供 SOCKS5 代理（支持认证） |
| 配置隧道 | 直接下发 FRP 原生配置（FRPC/FRPS，兼容 INI/TOML） |
| 节点套餐 | 查看各节点的套餐，创建隧道时需选择套餐 |
| 我的节点 | 把自己的公网服务器接入为节点 |
| 客户端日志 | 在线查看客户端运行日志，便于排障 |

## 组成

- **服务端（gostc-admin）**：后台管理 + API，内嵌前端页面。
- **客户端（gostc）**：运行在内网机器上，连接服务端并执行穿透配置；提供 Windows 图形版与命令行版。
- **节点（gostc -s）**：运行在有公网 IP 的机器上，提供穿透入口。
- **网关服务（gostc-proxy）**：实现自定义域名访问，可选部署。
